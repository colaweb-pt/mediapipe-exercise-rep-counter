# Generated Output Examples

Run `python run_demo.py --input input/example.mp4 --loops 4` to create the complete output set in `output/`:

- `landmarks_sample.json`
- `rep_events.json`
- `exercise_definition.json`
- `demo_summary.json`
- `edge_cases.md`

Generated files are intentionally ignored by Git because they depend on the user's source video. The repository includes the transformed portfolio video and contact sheet under `assets/`.
